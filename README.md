## Project Overview
This project analyzes global CO₂ emissions data over time. The dashboard provides insights into emissions from different sources such as coal, oil, and gas.

The goal of this project is to help users understand trends in emissions and compare data across years.



## Tools Used
- Microsoft Power BI

## Dashboard Pages

### 🔹 1. Global CO₂ Emissions Overview
- Displays key indicators such as:
  - Total CO₂ emissions  
  - Total population  
  - Average CO₂ per capita  
- Line chart showing emissions growth over time  
- Bar chart of top 10 countries by emissions  
- Year filter for interactive analysis  



### 🔹 2. Country Comparison
- World map showing CO₂ emissions by country  
- Bar chart of top emitting countries  
- Comparison of CO₂ emissions per capita  
- Highlights differences between large and small countries  



### 🔹 3. Emission Sources
- Stacked chart showing emissions from:
  - Coal  
  - Oil  
  - Gas  
- KPI cards for each emission source  
- Comparison chart between sources  
- Shows how energy sources contribute to emissions over time  



### 🔹 4. GDP vs CO₂ Analysis
- Scatter plot showing relationship between GDP and emissions  
- Demonstrates how economic growth affects CO₂ output  
- Interactive filters for country and year  



## Key Insights

- Global CO₂ emissions have increased significantly over time  
- The United States and China are major contributors  
- Coal remains the largest source of emissions  
- There is a strong relationship between GDP and emissions
